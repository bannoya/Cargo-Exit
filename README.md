# Cargo Exit

Primer juego de **Bannoya's Games**.

Cargo Exit es un puzle táctil para Android sobre cargar una camioneta. Cada paquete debe entrar en la cuadrícula y además poder salir por la puerta en el orden de entrega.

## Principios

- Gratis, sin anuncios y sin compras.
- Fácil de entender, interesante de dominar.
- Sin vidas, energía, rachas obligatorias ni castigos por dejar de jugar.
- Progresión mediante ideas nuevas, no mediante números inflados.
- Las herramientas y habilidades deben tener sentido dentro del trabajo de reparto.
- Funciona sin cuenta y sin conexión.

## Estado

Preproducción y vertical slice.

## Tecnología

- Unity 6.3 LTS (`6000.3.20f1`)
- C#
- Orientación vertical
- Android como plataforma principal
- Lógica de puzle independiente de la presentación
